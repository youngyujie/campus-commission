## 二、AI 协同段脚本（03:50 – 05:50）

> 用「一正一修」两段：一段展示用 Prompt 生成核心模块，一段展示引导 AI 修一个顽固 Bug。

### 4.1 用 Prompt 生成核心模块（约 70 秒）

**屏幕展示**：把下面 Prompt 原样输入 AI，再展示 AI 的方案与生成的代码（`hall.vue` 的分类分区、滑动指示条、滚动联动）。

```
把大厅改成「分类分区 + 滚动联动」：
1）列表按分类分成多个区块，每个区块有标题和条数；
2）顶部是一条吸顶导航，分类标签下面有一条滑动指示条；
3）页面滚动到哪个区块，指示条就平滑滑到对应标签；
4）点击标签，页面平滑滚动到对应区块；
5）动效统一 ease-out、300ms，简约干净，禁止弹跳/回弹。
只用真实数据，不要改数据层。
```

**讲解要点**：
- **你如何约束**：「只改 pages/components，不动 utils/store.js」；
- **AI 如何落地**：新建 `sections` 分组、`.topbar-ind` 滑动条、`updateActiveByScroll()` 滚动联动、`uni.pageScrollTo` 点击滚动。

### 4.2 引导 AI 修一个顽固 Bug（约 50 秒）

**屏幕展示**：先演示 Bug（切到发布页导航消失、退出后导航点不动），再贴 Bug 描述，展示 AI 定位与修复。

```
发现两个 bug：
1）底部导航切到「发布」时，导航栏会消失；
2）从发布页退出后，底部导航卡住、点不动。
我要的效果：点发布时底部导航不消失；
发布页的「发布订单」按钮原本固定在底部，现在要和其他内容一样随滚动移动；
离开发布后导航也能正常点。
```

**讲解要点**：
- AI 先定位根因：**发布页没挂载底部导航组件** + **导航内部「跳转中」的锁在 navigateTo 后未复位**，旧页残留导致锁死；
- 修复：发布页补导航、按钮改随内容滚动、跳转统一 `reLaunch` 并在回调复位锁；
- 现场验证：大厅 ↔ 发布 ↔ 我的，来回切换正常。

**录制技巧**：Prompt 用大字号贴出来让观众看清；AI 返回后不要全屏滚代码，用鼠标圈出关键函数名（`updateActiveByScroll`、`reLaunch`），再口述「我为什么这样约束它」。
