# AI 协作 · Prompt 历史快照（缺口 3 交付）

对应传智杯「2.1 AI 对话历史导出的 Prompt 历史快照」要求（需 ≥3 个核心迭代）。
本项目整理 **4 个核心迭代**，超量满足。

## 文件清单

| 文件 | 内容 |
|---|---|
| `01-配色.png` | 迭代① 统一主色：读交接文档+边界约束 → AI 改色 → 语义色纠偏 |
| `02-导航.png` | 迭代② 导航动效：参数化 Prompt → AI 实现 → 对比度纠偏 |
| `03-大厅.png` | 迭代③ 大厅重做：实装/滚动联动 Prompt → AI 改动 → 到底部/指示条纠偏 |
| `04-bug修复.png` | 迭代④ 发布页导航 Bug：现象 → AI 根因分析 → 修复 → 无头浏览器验收 |

## 三种提交形式（均已备好）

1. **截图**：本目录 4 张 PNG，2 倍分辨率，可直接放进提交材料。
2. **导出**：上级目录 `AI协作-Prompt快照.html` 是自包含可视化快照，双击即开，
   浏览器「打印 → 另存为 PDF」可导出图文版。
3. **录屏**：演示视频第 2–3 分钟「AI 协同复现」段，按 `演示视频脚本.md` 现场录制。

## 复现方式

截图内容依据 `docs/AI-协作记录.md` 的真实协作记录整理，可用脚本重新生成：

```bash
node scripts/gen-prompt-shots.js
```

（依赖 playwright-core + msedge，项目已配置）
