## ⚠️ 需要你手动完成（3 件事）

### 1. 推送到公开仓库（GitHub 或 Gitee）

```bash
# GitHub（先在网页上建一个空仓库 campus-commission，不要勾选 README）
git remote add origin https://github.com/你的用户名/campus-commission.git
git push -u origin main

# 或 Gitee
git remote add origin https://gitee.com/你的用户名/campus-commission.git
git push -u origin main
```

推完后到仓库 **Settings → 设为 Public**（或给评审开访问权限）。

> 当前提交作者是占位身份「校园委托开发 / dev@campus.local」。如果要用你的真实身份，先设置再推送：
> ```bash
> git config user.name "你的名字"
> git config user.email "你的邮箱"
> ```
> 若想连历史提交的作者一起改，告诉我，我给你一条重写命令。

### 2. 录制演示视频

- 按 `docs/演示视频脚本.md` 录 **5–8 分钟、1080p**；
- **必须含 ≥2 分钟的 AI 协同过程复现**（脚本 §二 已写好，直接照演）；
- 导出 MP4，上传到大赛官网。

### 3. 补 Prompt 截图（可选但建议）

- 把 `docs/AI-协作记录.md` 里 4 段迭代的「你的提问 + AI 回复」各截一张图；
- 放到 `docs/screenshots/` 下，命名 `01-配色.png`、`02-导航.png`…
- 这样「AI 对话历史」就有截图佐证，比纯文字更稳。
