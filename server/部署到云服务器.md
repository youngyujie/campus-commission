# 部署到云服务器（15 分钟）

这份是给「买一台机器，让同学都能用」准备的。腾讯云、阿里云、华为云的轻量应用服务器都通用，系统选 **Ubuntu 22.04** 就行。

---

## 一、买机器

### 在哪买

| 首选 | 链接 | 说明 |
|---|---|---|
| **腾讯云 · 云+校园** | `cloud.tencent.com/act/campus` | 学生认证后 2核2G 约 **75 元/年**（1.3 折） |
| 腾讯云 · 新用户特惠 | `cloud.tencent.com/act/pro/featured` | 没学生身份就走这个，首年也很便宜 |
| 阿里云 · 轻量 | `aliyun.com` 搜「轻量应用服务器」 | 备选，产品一样 |
| 华为云 · 云耀 | `huaweicloud.com` 搜「云耀云服务器」 | 备选 |

**学生身份认证**一般要学信网学籍截图或学生证，认证后才有校园价。限购 1 台。

### 下单时勾这些

| 项目 | 选什么 | 说明 |
|---|---|---|
| 产品 | **轻量应用服务器 Lighthouse** | 不是 CVM，不是 ECS |
| 配置 | **2 核 2G** | 几十个人用绰绰有余，1 核 1G 也跑得动 |
| 镜像 | **系统镜像 → Ubuntu 22.04 LTS** | 不要选「应用镜像」里的宝塔/WordPress |
| 地域 | 上海 / 广州 / 北京，离学校近的 | 延迟低 |
| 带宽 | 3–4 Mbps 足够 | 文字+小图，不是视频站 |
| 时长 | **买 1 年** | 续费比首购贵，别买 1 个月试用 |

### 三个最容易买错的地方

1. **买成 CVM / ECS** —— 贵一倍，还要自己配安全组、挂云硬盘，没必要。认准「轻量应用服务器」
2. **选了应用镜像** —— 宝塔面板、WordPress 这些预装环境会白占内存，而且我们用的是 Node，用不上
3. **忘记放行端口** —— 见下一节，这是 90% 的人第一次打不开页面的原因

### 关于备案

用 `http://公网IP:3000` 访问，**不需要备案**，买完立刻能用。

只有想绑自己的域名（如 `weituo.xxx.com`）走 80/443 才需要 ICP 备案，要等 1–3 周。给同学用完全不用等。

### 如果已经买成 Windows（重装成 Ubuntu）

2G 内存跑 Windows Server 本身就吃掉一大半，再跑 Node 会很紧。重装一次，5 分钟，磁盘会清空（新机器没数据，无所谓）。

```
实例详情 → 右上角「更多」→「重装系统」
→ 选「基于操作系统镜像」→ 点 Ubuntu 图标
→ 版本下拉框选 Ubuntu 22.04 LTS   ← 不要选 26.04
→ 登录凭证选「自定义密码」，设置密码
→ 确认
```

**版本别选最新的 26.04**：它太新，Node 官方安装包和很多文档还没跟上。22.04 最稳，24.04 也可以。

**用户名不是 root，是 `ubuntu`**。Ubuntu 镜像默认禁用 root 远程登录，登录用户是 `ubuntu`，它有 sudo 权限。设的密码是给 `ubuntu` 用的。

重装后公网 IP 不变。

## 二、放行端口（最容易忘的一步）

控制台 → 轻量应用服务器 → 你的实例 → **防火墙** → 添加规则：

```
应用类型：自定义
协议：TCP
端口：3000
来源：0.0.0.0/0
```

不放行这个，后面浏览器一定「连接超时」。

## 三、上传文件

### 方式 A：图形界面（推荐，不用记命令）

1. 下载 **WinSCP**（`winscp.net`，免费）
2. 新建连接：协议 SFTP，主机填公网 IP，用户 **`ubuntu`**，密码是重装时设的那个
3. 登录后，左侧选你电脑上的 `server` 文件夹，右侧进 `/home/ubuntu/`
4. 右键 → 上传，把整个 `server` 文件夹传上去

> 传完路径是 `/home/ubuntu/server`。

### 方式 B：命令行（Windows 自带 scp）

在你自己电脑上，进入项目的 `server` 目录，执行（把 IP 换成你的）：

```bash
scp -r ./* ubuntu@你的公网IP:/home/ubuntu/server/
```

### 方式 C：控制台网页终端（连不上 SSH 时用）

腾讯云控制台 → 你的实例 → 右上角「登录」，会开一个网页终端，用 `ubuntu` + 密码进。
但**网页终端没法传文件**，只能用来敲命令和排查问题。

> 提示：如果 scp 报 `Permission denied`，先用控制台「重置密码」设一个密码。

## 四、一键部署

SSH 登录服务器（注意用户是 `ubuntu`，不是 root）：

```bash
ssh ubuntu@你的公网IP
cd /home/ubuntu/server
sh deploy.sh
```

脚本会做这几件事：装 Node 22（走国内镜像，不用 apt）→ 复制到 `/opt/campus-commission` → 用 pm2 常驻 + 开机自启 → 自检接口 → 打印访问地址。

中间如果提示 `[sudo] password for ubuntu:`，输你重装时设的密码。

跑完会打印访问地址。

---

## 五、验证

浏览器打开：

```
http://你的公网IP:3000
```

- 能看到登录页 → 服务通了
- 打不开 → 先查防火墙 3000 端口，再 `pm2 logs campus` 看日志

**两台设备互相验证**（这一步才是关键）：

1. 手机浏览器打开同一个地址，注册一个账号，发布一条委托
2. 电脑浏览器打开同一地址，登录另一个账号
3. 电脑上的大厅应该能看到手机刚发的那条

看到 = 真共享，成功。

## 六、日常维护

```bash
pm2 status                  # 看状态
pm2 logs campus             # 看日志
pm2 restart campus          # 重启
pm2 stop campus             # 停止
```

**备份**就是复制一个文件：

```bash
cp /opt/campus-commission/data.json ~/backup-$(date +%m%d).json
```

**清空重来**：删掉 `data.json` 再 `pm2 restart campus`。

## 七、关于域名和备案

| 用法 | 要不要备案 |
|---|---|
| `http://IP:3000` | **不用** |
| 绑自己的域名走 80/443 | **必须 ICP 备案**，1–3 周 |

想给域名加 HTTPS（`https://weituo.xxx.com`）：

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
```

Nginx 反代配置（`/etc/nginx/sites-available/default` 里加）：

```nginx
server {
    listen 80;
    server_name weituo.xxx.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

然后 `sudo certbot --nginx -d weituo.xxx.com` 一条命令上 HTTPS。

> 提醒：国内服务器绑域名**必须先备案**，否则 80/443 会被拦。只想快速给同学用，就用 `IP:3000`，不用等备案。

## 八、必须先知道的三件事

**1. 没有登录鉴权**
任何人拿到地址就能调接口、能拉到全量数据（含手机号）。班级内部用可以，**别公开分享**。

**2. 整份数据会下发到每个浏览器**
现在的同步是「整份状态同步」，不是按需查询。数据量小的时候没问题，几千条以后会变慢。

**3. 同时改同一条会互相覆盖**
后写的赢。日常用基本碰不到。

要做到「正经产品」级别，得改成「按需查询 + 服务端鉴权 + 数据库」，那是另一轮工作。

## 附：如果只想临时演示（0 元）

不买服务器，本机跑起来 + 内网穿透：

```bash
cd server
node server.js          # 先起服务
npx localtunnel --port 3000     # 另开一个终端
```

会给你一个 `https://xxx.loca.lt` 的公网地址，直接发给别人就能看。

**限制**：你的电脑必须一直开着、不能休眠；免费版地址每次重启会变。适合答辩现场、临时给人看。
