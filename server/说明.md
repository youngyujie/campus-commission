# 校园委托 · 后端（多人共享版）

这个文件夹里就是一个完整的服务器。跑起来之后，**所有人看到的是同一份数据**：
一个账号在手机上注册，电脑上能登；你发的委托，别人刷一下就能看到。

---

## 三步跑起来

### 1. 装 Node.js

去 https://nodejs.org 下载 **LTS 版**，一路下一步。装完在命令行敲 `node -v`，能出版本号就行。

### 2. 启动

**Windows**：双击 `启动.bat`

**Mac / Linux**：
```bash
cd server
node server.js
```

看到这个就是成功了：

```
  校园委托 后端已启动
  ------------------------------------
  本机访问：  http://localhost:3000
```

### 3. 打开

浏览器访问 **http://localhost:3000**

网页和接口在同一个地址，不用改任何配置。

## 让别人也能用

### 情况一：同一个 WiFi（教室、宿舍）—— 最简单

1. 命令行敲 `ipconfig`（Mac 用 `ifconfig`），找到本机 IPv4，比如 `192.168.1.8`
2. 把 `http://192.168.1.8:3000` 发给同学
3. 如果打不开，是 Windows 防火墙拦了，允许 Node.js 通过即可

**限制**：你的电脑得一直开着；只能同一个局域网。

### 情况二：公网所有人都能访问

需要一台有公网 IP 的机器（云服务器 ¥10/月起）：

```bash
# 服务器上
scp -r server/ root@你的IP:/opt/campus
ssh root@你的IP
cd /opt/campus
node server.js          # 先手动跑通
npm i -g pm2
pm2 start server.js --name campus
pm2 save && pm2 startup # 开机自启
```

然后 Nginx 反代（可选，但推荐，能绑域名 + HTTPS）：

```nginx
server {
    listen 80;
    server_name 你的域名;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

**注意**：国内服务器 + 域名要 ICP 备案；只想临时给人看，用 `http://IP:3000` 一般不用备案。

## 数据在哪

全部在 **`data.json`** 一个文件里。

- **备份**：复制一份 `data.json` 就行
- **恢复**：把文件放回来，重启服务
- **清空重来**：删掉 `data.json`，重启

服务每次写入都是「先写临时文件再改名」，不会因为断电写坏。

## 之前那个静态链接还能用吗

能。同一份网页代码，两种模式自动切换：

| 打开方式 | 行为 |
|---|---|
| 通过这个服务（localhost:3000 或你的域名） | **共享模式**，所有人数据互通 |
| 通过 `apps.workbuddy.host` 那个静态链接 | **本地模式**，各存各的（和以前一样） |

判断依据：页面启动时会去请求 `/api/ping`，请求到就共享，请求不到就本地。

### 想让静态链接也连你的服务器

在链接后面加 `?api=你的服务器地址`，例如：

```
https://campus-commission-35470.apps.workbuddy.host/?sharecode=L6JLE2TLA6&api=http://192.168.1.8:3000
```

（服务器已经允许跨域，浏览器直接能调。）

## 同步是怎么做的

不是"每次操作都调接口"那么重，而是：

```
打开页面 → 先显示本地缓存（秒开）
        → 同时拉一次服务器数据 → 覆盖本地 → 刷新界面
操作数据 → 本地立刻生效
        → 300 毫秒后把「变了哪几条」推给服务器
每 4 秒  → 问一下服务器版本号变没变
        → 变了就拉全量、刷新界面
```

推的是**增量**（哪几条新增/修改/删除），不是整个数据库，所以流量很小。

## 已知限制（别踩）

1. **没有账号鉴权**。任何人拿到地址都能调接口。这是校园演示项目，别放真实隐私数据。
2. **整份数据会下发到每个浏览器**。也就是说，打开网页的人理论上能看到所有人的数据（包括手机号）。要做正经产品，必须改成"按需查询 + 服务端鉴权"。
3. **同时改同一条会互相覆盖**（后写的赢）。两个人同时编辑同一个订单，先推的会被后推的盖掉。日常使用基本遇不到。
4. **id 有小概率撞车**。id 是客户端按序号生成的，两个人同一瞬间新建可能撞。撞了表现为"少了一条"。演示规模下不会发生。
5. **只适合几十人**。数据全在内存 + 一个 JSON 文件，几百人同时在线会变慢。

## 出问题怎么查

**打不开 localhost:3000**
- `node -v` 有版本号吗？没装 Node
- 端口被占用：换一个，`PORT=3001 node server.js`

**同学打不开我的局域网地址**
- 防火墙：Windows 安全中心 → 允许应用通过防火墙 → 勾上 Node.js
- 确认在同一个 WiFi（不要一个连 5G 一个连 2.4G 的不同网段）

**数据不同步**
- 打开浏览器控制台（F12），看有没有 `[同步] 已连接后端`
- 如果显示"没检测到后端"，说明页面不是从这个服务打开的

**数据乱了想重来**
- 停服务，删 `data.json`，重启，重新注册
